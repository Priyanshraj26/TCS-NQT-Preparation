## How to Use

### For Aptitude & Theory
1. Open the PDFs in `01-Aptitude/PDFs/` or `03-Core-CS-Subjects/PDFs/`
2. Print them for offline study or read on tablet
3. Use Quick Reference PDF for last-minute revision

### For Coding Practice
1. Read the problem in `02-Coding/DSA-Questions/[Topic]/`
2. Try solving it yourself first (15-30 min)
3. Check solution in `02-Coding/Solutions-CPP/[Topic]/`
4. Track progress using `02-Coding/Top-50-Most-Asked/README.md`

### Compiling C++ Solutions
```bash
# Compile
g++ -std=c++17 -O2 -Wall solution.cpp -o solution

# Run
./solution

# With input file
./solution < input.txt
```

## Exam Day Checklist

- [ ] Carry valid ID proof
- [ ] Reach center 30 minutes early
- [ ] Attempt easy questions first
- [ ] Don't spend >2 min on any aptitude question
- [ ] For coding: read all questions first, start with easiest
- [ ] Manage time: keep 5 min buffer for review
- [ ] Stay calm and confident

---

## Tips for Effective Preparation

1. **Consistency over intensity** - 2 hours daily beats 10 hours on weekends
2. **Practice coding daily** - Solve at least 2-3 problems every day
3. **Time yourself** - Practice under exam conditions
4. **Revise formulas weekly** - Use the Quick Reference PDF
5. **Take mock tests** - Simulate the real exam environment
6. **Focus on weak areas** - Track your performance and improve
