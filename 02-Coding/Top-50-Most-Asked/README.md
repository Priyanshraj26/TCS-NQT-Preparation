## Patterns to Master

### Pattern 1: Two Pointers
**Questions:** Q1, Q3, Q8, Q14, Q24  
**Key:** Two pointers traversing from both ends or same direction  
**Typical complexity:** O(n) time, O(1) space

### Pattern 2: Sliding Window
**Questions:** Q2, Q16  
**Key:** Maintain a window, expand/shrink based on condition  
**Typical complexity:** O(n) time

### Pattern 3: Hash Map
**Questions:** Q1, Q4, Q10, Q15, Q18  
**Key:** Trade space for time with O(1) lookups  
**Typical complexity:** O(n) time, O(n) space

### Pattern 4: Binary Search
**Questions:** Q43, Q46, Q10 (square root)  
**Key:** Search space halving on sorted/monotonic data  
**Typical complexity:** O(log n) time

### Pattern 5: DFS/BFS
**Questions:** Q26-Q36  
**Key:** Tree/graph traversal, cycle detection, shortest path  
**Typical complexity:** O(V+E) time

### Pattern 6: Dynamic Programming
**Questions:** Q37-Q42  
**Key:** Overlapping subproblems + optimal substructure  
**Approach:** Identify state, recurrence, base case

### Pattern 7: Stack
**Questions:** Q47, Next Greater Element  
**Key:** LIFO for matching, monotonic stack for next greater/smaller
