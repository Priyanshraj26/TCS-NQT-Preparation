# Solution: Sort Array of 0s, 1s, 2s (Dutch National Flag)

[← Back to Question](../../DSA-Questions/Arrays/Q008-sort-012.md)

## Approach Overview

| Approach | Time Complexity | Space Complexity | Recommended |
|----------|----------------|------------------|-------------|
| Counting Sort | O(n) — 2 passes | O(1) | ✗ |
| Dutch National Flag (3 pointers) | O(n) — 1 pass | O(1) | ✓ |

---

## Approach 1: Counting Sort

### Intuition
Count occurrences of 0, 1, 2, then overwrite the array.

### C++ Code
```cpp
#include <iostream>
#include <vector>
using namespace std;

class Solution {
public:
    void sortColorsCounting(vector<int>& nums) {
        int c0 = 0, c1 = 0, c2 = 0;
        for (int x : nums) {
            if (x == 0) c0++;
            else if (x == 1) c1++;
            else c2++;
        }
        int i = 0;
        while (c0--) nums[i++] = 0;
        while (c1--) nums[i++] = 1;
        while (c2--) nums[i++] = 2;
    }
};

int main() {
    Solution sol;
    vector<int> nums = {2, 0, 2, 1, 1, 0};
    sol.sortColorsCounting(nums);
    for (int x : nums) cout << x << " "; // 0 0 1 1 2 2
    cout << endl;
    return 0;
}
```

## Approach 2: Dutch National Flag (Optimal — Single Pass)

### Intuition
Use three pointers: `low`, `mid`, `high`.
- Everything before `low` is 0
- Everything between `low` and `mid` is 1
- Everything after `high` is 2
- `mid` scans through the array:
  - If `nums[mid] == 0`: swap with `low`, increment both
  - If `nums[mid] == 1`: just increment `mid`
  - If `nums[mid] == 2`: swap with `high`, decrement `high` (don't increment `mid` — the swapped element needs checking)

### C++ Code
```cpp
#include <iostream>
#include <vector>
using namespace std;

class Solution {
public:
    void sortColors(vector<int>& nums) {
        int low = 0, mid = 0, high = (int)nums.size() - 1;

        while (mid <= high) {
            if (nums[mid] == 0) {
                swap(nums[low], nums[mid]);
                low++;
                mid++;
            } else if (nums[mid] == 1) {
                mid++;
            } else { // nums[mid] == 2
                swap(nums[mid], nums[high]);
                high--;
            }
        }
    }
};

int main() {
    Solution sol;

    // Test 1
    vector<int> v1 = {2, 0, 2, 1, 1, 0};
    sol.sortColors(v1);
    for (int x : v1) cout << x << " "; // 0 0 1 1 2 2
    cout << endl;

    // Test 2
    vector<int> v2 = {2, 0, 1};
    sol.sortColors(v2);
    for (int x : v2) cout << x << " "; // 0 1 2
    cout << endl;

    // Test 3: all same
    vector<int> v3 = {1, 1, 1};
    sol.sortColors(v3);
    for (int x : v3) cout << x << " "; // 1 1 1
    cout << endl;

    // Test 4: already sorted
    vector<int> v4 = {0, 0, 1, 2, 2};
    sol.sortColors(v4);
    for (int x : v4) cout << x << " "; // 0 0 1 2 2
    cout << endl;

    return 0;
}
```

### Dry Run
**Input:** `[2, 0, 2, 1, 1, 0]`

| Step | low | mid | high | nums[mid] | Action | Array |
|------|-----|-----|------|-----------|--------|-------|
| 0 | 0 | 0 | 5 | 2 | swap(0,5), high-- | [0,0,2,1,1,2] |
| 1 | 0 | 0 | 4 | 0 | swap(0,0), low++, mid++ | [0,0,2,1,1,2] |
| 2 | 1 | 1 | 4 | 0 | swap(1,1), low++, mid++ | [0,0,2,1,1,2] |
| 3 | 2 | 2 | 4 | 2 | swap(2,4), high-- | [0,0,1,1,2,2] |
| 4 | 2 | 2 | 3 | 1 | mid++ | [0,0,1,1,2,2] |
| 5 | 2 | 3 | 3 | 1 | mid++ | [0,0,1,1,2,2] |
| 6 | mid > high → stop |

**Output:** `0 0 1 1 2 2`

### Complexity Analysis
- **Time:** O(n) — single pass
- **Space:** O(1) — in-place swaps

## Common Mistakes
1. Incrementing `mid` after swapping with `high` — the swapped element hasn't been checked yet
2. Using `mid < high` instead of `mid <= high` — misses the case when mid equals high
