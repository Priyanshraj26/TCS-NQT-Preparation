# Sort Array of 0s, 1s, 2s (Dutch National Flag)

**Difficulty:** Medium  
**Topic:** Array  
**Source:** TCS NQT  
**Frequency:** ★★★★★

## Problem Statement
Given an array consisting only of 0s, 1s, and 2s, sort it in-place in a single pass without using any sorting algorithm.

## Input Format
- First line: integer `n` (size of array)
- Second line: `n` space-separated integers (each 0, 1, or 2)

## Output Format
- The sorted array as space-separated integers

## Constraints
- 1 <= n <= 10^5
- nums[i] is 0, 1, or 2

## Examples

### Example 1:
**Input:**
```
6
2 0 2 1 1 0
```
**Output:**
```
0 0 1 1 2 2
```

### Example 2:
**Input:**
```
3
2 0 1
```
**Output:**
```
0 1 2
```

## Hints
<details>
<summary>Hint 1</summary>
Use three pointers: low, mid, high. Elements before low are 0s, between low and mid are 1s, after high are 2s.
</details>

<details>
<summary>Hint 2</summary>
This is the Dutch National Flag problem by Dijkstra.
</details>
